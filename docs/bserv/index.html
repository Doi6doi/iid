In-browser IID server

This is a simple IID server to show how IID calls can work. You can choose one of the custom calls to see the replies to them.

Each call can be tried through different scenarios. The connection between the caller and the server can be SAFE, KNOWN, or INSECURE.
Read the draft for the exact meaning of those.

The caller itself can be ANONYMOUS, FOREIGN, KNOWN, TRUSTED. The answers ofthe server will be different based on the server's preferences.
